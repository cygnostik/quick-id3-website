Install & first open.

Install the Mac beta

0.1.0-beta.2 · Apple Silicon Mac · macOS 27 or later.

  1. Open the disk image and drag QuickID3.app into Applications.
  2. Eject the disk image, then open QuickID3 from Applications.
Read installation notes ↗
If macOS asks for approval

This beta is ad-hoc signed and is not notarized by Apple. If macOS blocks it as an unidentified or unverified developer, attempt to open it once, then go to System Settings → Privacy & Security → Open Anyway.

Confirm only if this is the download you intended to install. Do not disable Gatekeeper. If macOS reports malware or damaged software, stop rather than bypassing that warning.

Apple’s first-open instructions ↗
Install the Windows beta

0.1.0-beta.2 · x64 PC · 64-bit Windows 10 version 1809 or newer, or Windows 11.

  1. Extract the entire ZIP to a writable folder. Keep QuickID3.exe, the DLLs and plugin folders together. Do not run the app from inside the ZIP.
  2. If the app reports a missing VCRUNTIME/MSVCP DLL, install the latest Microsoft Visual C++ x64 runtime directly from Microsoft, then reopen QuickID3.exe. Administrator permission may be required.
  3. Open QuickID3.exe, browse to an MP3 folder, select tracks and edit. Ctrl+S saves changes to the original files without re-encoding audio.

The Microsoft runtime is a separate system prerequisite, not included in the ZIP. The portable folder does not install Quick·ID3 or require Qt/TagLib SDKs.

Preferences stay in your Windows user profile, not in the portable folder. To remove the app, close it and delete its extracted folder.

Read installation notes ↗
Windows signing & validation

This beta is unsigned (not Authenticode signed). Windows may show an unknown-publisher or SmartScreen warning.

The Qt runtime supports the Windows systems listed above. This beta’s automated native checks run on Windows Server 2022; physical multi-monitor setups and other Windows versions have not been validated by those checks.

What is included in this beta?

Local MP3 browsing, single and multiple track editing, front-cover artwork, release credits, comments, lyrics, inline edits and in-place Save.

Keep independent copies of important music before using beta software. Save writes all edited tracks in the current folder, including tracks no longer selected.
